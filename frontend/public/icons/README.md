# Icons

Every file here is currently a **fully transparent placeholder**, generated by
`backend/scripts/make_placeholder_icons.py`. To use real artwork, replace each file with one that
has the **same name and size**. No code change is needed.

| File | Size (px) | Used for | Notes |
|---|---|---|---|
| `train-eip.png` | 48×48 | Express InterCity Premium (Pendolino) | Draw pointing **up (north)**: markers are rotated to the direction of travel. The anchor is the centre. |
| `train-eic.png` | 48×48 | Express InterCity | same |
| `train-ic.png` | 48×48 | InterCity | same |
| `train-tlk.png` | 48×48 | Twoje Linie Kolejowe | same |
| `train-ec.png` | 48×48 | EuroCity | same |
| `train-en.png` | 48×48 | EuroNight | same |
| `train-default.png` | 48×48 | any other category | same |
| `station.png` | 16×16 | stations (shown from zoom 8) | The anchor is the centre. |

Keep a transparent margin in the train icons: the marker draws a delay ring (green ≤ 5 min,
amber ≤ 20 min, red above that) with a 26 px diameter behind the icon. Leave the ring visible, or
at least don't cover it completely.

While the placeholders are in use, each marker also shows a filled dot and a category label so the
map stays readable. Once real icons are in place, turn that off in `src/lib/icons.ts`:

```ts
export const SHOW_FALLBACK_LABEL = false;
```

The icon list lives in `src/lib/icons.ts` and in `backend/scripts/make_placeholder_icons.py`.
To add a category, add it to both files.
